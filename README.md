# GameHarness

An extensible runtime for LLM agents that play games, create reusable skills and reactive policies, and improve their control through experience. Games connect through adapters; strategic models and fast decision providers connect independently.

## Running the project

The repository currently contains the design specification. There is no runnable application or installation command yet.

Minecraft Java is the first planned complete game integration. The core runtime is designed for additional games rather than Minecraft-specific strategies.
