## Bounded exports and derived evidence

Readonly summaries derive from the original retained event prefix, including
late observers; counted tool entries are not transport attempts. Compact export
continues logical records with record/chunk cursors; total counts records, not
chunks. Oversized records retain ordered JSON text, SHA-256 and byte counts.
Raw paged reads have separate snapshots, not one cross-page transaction.

Objective metrics pin one complete published generation/source boundary across
all pages, including pending-source provenance. Before first publication,
objective metrics are explicitly unavailable/pending, never an empty completed
array. Missing previously published generations are corruption.

Schema7 incrementally materializes metrics/program evidence from source MVCC via
bounded readonly previews and atomic writer commits. Only complete generations
are visible; raw event/trace prefixes and usage qualification retain independent
semantics. Query/capacity/persistence failures remain explicit, prohibit false
platform pass and still close readers. Private journal completeness cannot be
inferred from compact reports.

Host verification of these mechanisms proves neither native timing/continuity,
gameplay efficacy, P06 acceptance nor full E01. Original failed/late/interrupted/
unrun slots remain original outcomes.
