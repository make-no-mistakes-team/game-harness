# Integration evidence: bounded natural-model negatives

These immutable negative cohorts tested model-authored GameHarness programs.
They neither qualify ordinary local Survival nor authorize reopening an
exhausted historical comparison. Current development policy is separate.

## Luna/Sol natural wood comparison

One wood attempt per model used the same technical hypothesis.
Both retained `platform_status:pass`, `agent_status:goal_not_verified` and
`provider_status:unknown`, with zero durable actions, registered sources or
executions. All five cleanup resources closed; neither evaluator reported a
terminal failure. Only wood ran live: crafting-table and stone scenarios were
implemented/tested definitions, not live outcomes.

| Model | Wall time | Host admissions / usage messages | Reported uncached / cache-read / output |
| --- | --- | --- | --- |
| Luna | 109.15 s | 12 / 11 | 40,586 / 55,936 / 2,896 |
| Sol | 176.52 s | 12 / 11 | 15,148 / 106,624 / 3,352 |

Cache-write subtotals were zero. Full consumption and subscription cost remain
unknown because each report covered only 11 usage messages.
The governance ledger had exactly two settled unsuccessful rows under this
hypothesis, exhausting the allowance then in force. There was no authorized
third attempt or budget reset in this comparison.

Luna supplied `based_on:1` for a new name and received five conflicts;
Sol received six across two names. Local SDK schemas made the field optional
and the host correctly rejected revision metadata for a new name.
The actual transport omitted `strict`, but the effective remote grammar was
not captured. Strictness was not established as the cause or sole model fault.

The [official function-calling guidance](https://developers.openai.com/api/docs/guides/function-calling#strict-mode)
described Responses normalization when strictness is omitted and the
`strict:false` opt-out. A zero-network actual-SDK-builder regression modeling
that normalization first failed, 0/1 in 62.37 ms: initial creation could not
omit `based_on`. This was local contract evidence, not a captured remote grammar.
The production change set only `AgentTool.strict:false`, preserving host
validation, conflicts, authority, ownership and isolation.
The same regression passed 1 test / 12 assertions in 616 ms, followed by
typecheck and 295 tests / 1,827 assertions. No model/native/UI rerun followed
that provider-only change in this cohort. Its gameplay effect remained untested.

## Sol collection-to-crafting attempt

One separately justified higher-capability attempt asked **“Collect wood and
craft a crafting table.”** It used discovered text/image support, fresh
ordinary Normal Survival, empty inventory and fresh working programs.
No tactics, items or coordinates were supplied.
Its allocation was **30 host admissions, 300,000 ms gameplay and
900,000 ms total**; two earlier unsuccessful wood attempts remained retained.

The result was platform pass / agent goal not verified / provider unknown.
It stopped at the gameplay deadline with all eight cleanup resources closed
and native cleanup confirmed. Three search revisions and one recovery program
validated and ran, with no retained capability/validation failure.
There were 28 camera actions, 81 movement intervals and one explicit successful
respawn, but no navigation, digging or crafting action and no inventory gain.
Two drowning deaths occurred during replanning. Recovery adopted the first
new life; the deadline interrupted the second recovery turn.
The final observation was dead, in water and empty-handed.

Blocked feedback reached later contexts. No missing-critical-feedback,
confirmed pathfinder defect or crafting fault was established.
Low-level action success was not useful traversal or resource progress.
The selected historical diagnostic investigation used a synthetic controller
and zero inference; its selection was not a new gameplay result or permission
for repeated paid attempts.

There were 22 admissions, 22 SDK-visible image-referenced contexts and 22
usage events: 19 tool-use completions and three aborts, two for death and one
for deadline. Reported subtotals were 69,635 uncached / 103,552 cache-read /
0 cache-write / 3,586 output. Aborts had SDK-zero counters and no response IDs;
actual consumption, wire attempts and subscription cost remain unknown.
No SDK-visible provider/HTTP error was retained.
Connect-only tracing supported the configured local-proxy route but could not
attribute every descendant connection or equate socket connects with requests.

The journal retained 9,032 permitted records without journal failure, excluding
hidden reasoning and credentials. It included 1,234 pre-cap execution records
but omitted diagnostic branch decisions for all three search roots.
This was not a complete branch trace.
All 9,002 delivered PNGs were retained, with one disclosed upstream missing
sequence and maximum 65 ms gap. Capture lasted 300,176 ms; replay 300,240 ms,
a 64 ms difference. The movie was a derivative, not one encoded frame per PNG.
Native observations established both deaths; inspected replay samples showed
authentic terrain, water and drowning. There was no audio, synchronized
state/pixel proof or strict-visual claim.

No learning, improvement, cost-per-success or release result follows.
See [other gameplay cohorts](integration-gameplay.md) for positive small tasks
that remain separate from these failures.
