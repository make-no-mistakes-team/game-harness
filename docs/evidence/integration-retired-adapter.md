# Integration evidence: retired Node/Mineflayer adapter

These results belong to the removed Mineflayer/prismarine adapter and browser
UI. They do not certify native sensing, cancellation, current button layout
or [current lifecycle](../reference/lifecycle.md).
No historical procedure here is a current launch instruction.

## Model and navigation results

One new ordinary Survival world exercised real OMP OAuth/discovery and
16 provider-reported `gpt-6-luna` calls. The model authored/validated/activated
two local-JS policies. The first had no confirmed effect and was retired.
“Search toward observed oak canopy” produced an attributed action with about
7.28 blocks of observed movement and a camera change.
Inventory stayed empty and the model reported incomplete.
This was inference plus policy effect, not wood collection, useful survival,
speedup or playable acceptance.

Controlled vanilla fixtures covered behind-camera observation, concealed ore
exclusion followed by dig/reveal, occluded-entity last-seen memory, coarse
heard sound and rejection of unknown navigation targets before private
geometry access. Distant unrelated chunk arrivals had wrongly invalidated
long digs; correction retained relevant chunk/ray revocation.

The full navigation comparison **failed**: after partial motion a replan hit
its declared 5 ms guard at about 5.42 ms. It reported failure, not arrival,
and never reached the second material-substitution variant.
Neither budget nor acceptance was relaxed.
A later separate user run confirmed one actual log removal before another
dig's uncertain preemption caused safety pause. Another active-run snapshot
recorded actual creeper death while digging; it did not show regression of
the pre-FINISH correction. These observations do not upgrade the original
movement-only empty-inventory run.

## Cancellation, death and old controls

Old Pause could retain a connected player after confirmed neutralization,
while uncertain cancellation could disconnect/fence it.
An idle connected avatar died to a creeper; the adapter's death fixture
verified disconnect, first-cause preservation and no late writers.
Death and unknown action outcome remained separate evidence.
The old Stop-run contract required client disconnect but retained the server;
Stop-world also stopped the server. Closing the browser stopped neither.
Those disconnect rules were superseded, not carried into the native contract.

The selected real-server pre-FINISH dig cancellation passed SDK drain and
server ABORT acknowledgement, with no delayed FINISH across the old timer
window. The connection stayed live and a later camera action worked.
The independent witness recorded block state separately.
`cancelled` with `prior_effects:"unverified"` did not mean the block stayed
unchanged. Missing FINISH/ABORT acknowledgement, failed cleanup or transport
loss stayed unknown and fenced.
No fixture pass retroactively resolved earlier unknown actions.

One uncertain-cancellation session subsequently accepted Stop on its settled
paused run, disconnected, and rejoined the still-running world without another
inference call. A created-but-not-started run could reconnect without changing
its ID/task/goal/model or starting inference. These are old UI semantics.

After reversible-look drain correction, selected real-server fixtures passed
same-owner simultaneous movement/look/observed-target attack, competing-owner
rejection, cancellation and stable post-cancel position. Held-shield release
had server metadata evidence. The “pending inference” interval was synthetic,
not live strategic overlap, complete recovery coverage or a full-suite pass.

## Sandbox and presentation infrastructure

Actual sandbox scenarios exercised 128 MiB / 0.5 CPU / 32 PIDs, no network,
unprivileged/read-only/capability-dropped containers; infinite-JS reaping;
private JSON state; and invalid shell-like-proposal rejection.
A detached host guardian removed containers after host loss even if generated
code removed its in-container EOF handler. Docker outage kept cleanup pending
until removal could be confirmed; absence of ACK was not termination success.

A Docker smoke passed in 5.9 s with 1,200 ms host-capability wait, nested
containers, cancellation without late calls and external infinite-CPU shutdown.
A separate Store/SkillManager/Docker tree smoke passed in 3.23 s:
blocked child/safely failed leaf handled by the authored parent; two successful
roots across two runs; exact scoped imports; four synthetic broker actions;
retry/reopen start-key identity and monotonic epochs.
These were real isolation/persistence paths with synthetic effects, not
provider gameplay, promotion or savings.

Prismarine height/section patches, a narrow AJV-worker CSP exception, Chrome
terrain rendering and an OMP-browser blob-worker conflict belonged to that
removed renderer. They are not native prerequisites.
The full recovery/soak, cold/warm, policy, Jev, two-auth-category,
two-provider and full-game goals were not closed by these cohorts.
